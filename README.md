# Supply Network Planning (SNP) Heuristic Engine

Модуль распределения ограниченного товарного запаса между конкурирующими заявками в условиях дефицита

#### Основные гипотезы
* Справедливое распределение: Пропорциональное деление дефицита между заявками одного приоритета.
* Соблюдение лимитов: Применение ограничений по минимальным партиям (`min_lot`) и кратностям (`rounding_value`).
* Защита от перепоставки: Округление всегда идет вниз, отгрузка алгоритмически не может превысить запрошенный `demand_qty`.

#### Логика алгоритма (Two-Pass Apportionment)
Ядро не использует тяжелые сторонние библиотеки и решает задачу за два прохода:
1. Базовые доли: Вычисляется коэффициент нехватки товара, и каждая заявка получает свою долю, округленную вниз до своей транспортной кратности.
2. Дораздача остатков: Нераспределенный из-за округлений сток передается тем заявкам, которые потеряли наибольший процент объема на первом шаге.

#### Установка и запуск

Для Mac / Linux:

```bash 
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && python main.py && pytest -v test_allocator.py
```

Для Windows (PowerShell):

```bash
python -m venv .venv ; .\.venv\Scripts\activate ; pip install -r requirements.txt ; python main.py ; pytest -v test_allocator.py
```

#### Структура проекта
* allocator.py - ядро алгоритма.
* main.py - точка входа, I/O операции.
* test_allocator.py - тесты гипотез (min_lot, перепоставка, детерминированность).
* data/ - исходные данные (supply.csv, requests.csv).
* REPORT.md - отчет и обоснование решения.
